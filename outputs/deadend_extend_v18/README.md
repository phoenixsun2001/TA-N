# 断头路延长切分实验

基于 v17 POI 切分原投影图层。采用高速至三级道路及连接线、居住区道路和未分类道路中标记地面层的道路，排除桥隧和负层。道路在街区内裁剪、按拓扑拼接，长度至少 50 米，一端靠近街区边界 2 米以内，另一端沿最后约 20 米道路方向延长到另一侧边界，延长距离上限为 100 米。输出切分线和推测延长段。对中心线位于街区外且端点距街区 15 米内的凹口道路，也沿端点方向在最长 100 米内寻找穿过街区的路径。仅接受有效单面、无内环，且新面每个至少 100 平方米的切分。100 米、50 米、2 米、15 米和 100 平方米均是实验参数。

第一阶段 2674 条延长线切分 2078 个源街区，延长线最大 99.97 米、中位数 41.94 米；第二阶段有 7588 个候选、接受 5107 个延长切分。最终 56871 个投影面，0 无效和 0 内环；GCJ 图层同样 0 无效、0 内环。两阶段面积差分别约 -0.0001 和 -0.143 平方米，属于精度/阈值级变化。上海理工大学截图附近的一个原始街区也被切分，但尚未确认截图中每条道路均按照预期处理。

道路端点可能只是原始数据分段，不一定是现实中的断头路；100 米射线可穿过建筑、园区或水域边缘，未验证地面障碍及行人可达性。道路名取邻近线，拼接后可能不代表整条线。辅助切分线并非实际道路。GCJ 仍使用此前外环填充的近似转换，可能覆盖其他面或水面，预计和投影图层不完全一致；原有面重叠未处理。继承的 POI 和影像属性没有对子面重新统计。应结合地图审核延长线。
